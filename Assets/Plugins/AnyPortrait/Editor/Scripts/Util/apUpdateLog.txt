<size=16>AnyPortrait Update Log v1.6.0 / v1.6.1</size>
(April 30, 2025 / August 6, 2025)

<size=13>Improvements</size>

- <color=blue>Masks</color>
    The ability to create and send a render texture that acts as a mask and similar has been greatly improved.
    Unlike clipping masks, masks can be created and sent regardless of the rendering order of the meshes.
    Multiple meshes can create a single mask together.
    Custom properties can be passed with masks.
    The ability to combine multiple masks is added.
    Instead of an alpha mask, a mask texture generated with a regular shader can be passed with the Alpha value to implement a "See-Through" effect.
    "As Mask Only" option is added to set a mesh that does not actually render, but only serves as a mask provider.
    An option to size render textures for masks based on screen size is added.
    Improved "v16" material presets is added to support mask functionality, and old material presets and packages are classified as "Legacy".

- <color=blue>Editor Docking</color>
    AnyPortrait editor can be run docked within the Unity editor layout.
    An issue is fixed where the editor would terminate when "Maximized" while docked.
    An issue is fixed that occurred when switching to another scene while the editor was docked.

- <color=blue>Animation-related Scripts</color>
    To check the length of the animation, the "TimeLength" and "Duration" properties are added to apAnimPlayData, and the "GetAnimationTimeLength" and "GetAnimationDuration" functions are added to apPortrait.
    To check whether the animation is looped, the "IsLoop" property is added to apAnimPlayData, and the "IsAnimationLoop" function is added to apPortrait.
    The "OnAnimationEnded" event is added to apPortrait to detect when the animation being played has ended or reached the last frame.
    "PauseAt" and "ChangeFrame" functions to change the frame of an animation are added. (v1.6.1)

- <color=blue>Bake Option Validation</color>
    Automatic validation of key Bake options is added that need to be set to match the project environment, such as "Render Pipeline", "Color Space", and "Number of Cameras".
    This feature is added to the Bake dialog, and some options are moved to the Settings tab.

- It is improved that the "Reserved Properties" used inside AnyPortrait in the "Material Library" are automatically determined based on the set shader asset.
- "Move Symmetrically" function in the mesh editing screen.
- A function is added to move the axis to the pivot when using the Mirror tool in the mesh editing screen.
- Assembly definition (asmdef) file is added so that AnyPortrait scripts are compiled separately.
- Webpage links have been modified due to the website renewal. (v1.6.1)



<size=13>Fixed issues</size>

- An issue is fixed where an error related to the render texture would occur when the AnyPortrait editor was too small.
- An issue is fixed where the value of the RGB channel would be affected by the Alpha value when the background color was semi-transparent during screen capture.
- An issue is fixed where the data of keyframes would be initialized and unrecoverable when undoing after deleting the timeline of an animation, etc.
- An issue is fixed where the gizmo would not work when undoing after deleting the timeline of an animation, etc.
- An issue is fixed where all lines connecting existing vertices would disappear when undoing after adding vertices in the mesh editing screen.
- An issue is fixed where undoing after creating a new character or Bake would not be performed properly.
- An issue is fixed where a strange image was output to the upper left of the workspace in Unity 2022 or earlier.
- An issue is fixed where an error log related to the command buffer occurred when running with URP in Unity 6.
- An issue is fixed where some list UIs, such as Add Timeline and Add Modifier, were output awkwardly in Unity 6.
- An issue is fixed where the UI for copying and pasting vertices of a mesh was output somewhat small in Unity 2023 or later.
- An issue is fixed where the initial Alpha would be 0 when adding a new key depending on the editor settings when editing the "Color Only (Controller)" modifier.
- An issue is fixed where the brush icon in the rigging edit screen would scale up/down with the screen zoom.
- An issue is fixed where the editor would not be able to edit modifiers due to an error when deleting a mesh registered to a Rigging or Physics modifier and then restarting it immediately.
- An issue is fixed where clipped meshes would not render in frames where the clipping mask was hidden and then shown. (v1.6.1)
- An issue is fixed where an error would occur when synchronization of two characters playing as Mecanim was released. (v1.6.1)

<size=16>AnyPortrait 업데이트 로그 v1.6.0 / v1.6.1</size>
(2025년 4월 30일 / 2025년 8월 6일)

<size=13>개선된 사항</size>

- <color=blue>마스크</color>
    마스크 및 유사한 역할을 하는 렌더 텍스쳐를 생성하고 전달하는 기능이 크게 개선됨
    클리핑 마스크와 달리, 메시의 렌더링 순서에 무관하게 마스크를 생성하고 전달할 수 있음
    여러개의 메시들이 하나의 마스크를 같이 생성하여 전달할 수 있음
    마스크로서의 렌더 텍스쳐 및 사용자 지정 프로퍼티를 전달할 수 있음
    여러개의 마스크들을 조합하는 기능이 추가됨
    알파 마스크 대신 일반 쉐이더로 생성된 마스크 텍스쳐를 Alpha 값과 함께 전달하여 "투과 효과(See-Through)" 구현이 가능함
    실제로 렌더링은 안되지만 마스크 제공 역할만 하는 메시를 설정하기 위한 "As Mask Only" 옵션이 추가됨
    화면의 크기에 따라 마스크용 렌더 텍스쳐의 크기가 결정되는 옵션이 추가됨
    마스크 기능을 지원하도록 개선된 "v16" 재질 프리셋이 추가되었으며, 이전 재질 프리셋과 패키지들이 "Legacy"로 분류됨

- <color=blue>에디터 도킹</color>
    AnyPortrait 에디터를 유니티 에디터 레이아웃 내에 도킹한 상태로 실행 가능
    에디터가 도킹된 상태에서 "최대화(Maximize)"시 에디터가 종료되는 문제가 수정됨
    에디터가 도킹된 상태에서 다른 씬으로 전환할 때 발생하는 에러가 수정됨

- <color=blue>애니메이션 관련 스크립트</color>
    애니메이션의 길이를 확인할 수 있도록, apAnimPlayData에 "TimeLength"와 "Duration" 프로퍼티가 추가되고, apPortrait에 "GetAnimationTimeLength"와 "GetAnimationDuration" 함수가 추가됨
    애니메이션의 루프 여부를 확인할 수 있도록, apAnimPlayData에 "IsLoop" 프로퍼티가 추가되고, apPortrait에 "IsAnimationLoop" 함수가 추가됨
    재생되는 애니메이션이 종료되거나 또는 마지막 프레임 도달했음을 감지하기 위한 "OnAnimationEnded" 이벤트가 apPortrait에 추가됨
    애니메이션의 프레임을 변경하는 "PauseAt"과 "ChangeFrame" 함수가 추가됨 (v1.6.1)

- <color=blue>Bake 옵션 유효성 검사</color>
    "렌더 파이프라인", "색상 공간", "카메라 개수"와 같은 프로젝트 환경에 맞추어서 설정해야하는 주요 Bake 옵션들의 유효성을 자동으로 검사하는 기능이 추가됨
    해당 기능이 Bake 다이얼로그에 추가되었으며, 이에 따라 일부 UI가 Setting 탭으로 이동됨

- "재질 라이브러리"에서 AnyPortrait 내부에서 사용되는 "예약된 프로퍼티(Reserved Property)"들이 설정된 쉐이더 에셋에 따라 자동으로 결정되도록 개선됨
- 메시 편집 화면에서 "버텍스 대칭 이동" 기능이 추가됨
- 메시 편집 화면에서 미러 편집시의 축을 피벗(Pivot)으로 이동시키는 기능이 추가됨
- 어셈블리 정의(asmdef) 파일을 추가하여 AnyPortrait 스크립트들이 별도로 컴파일되도록 변경됨
- 홈페이지 리뉴얼에 따라 웹페이지 바로가기 링크가 수정됨 (v1.6.1)



<size=13>수정된 문제점</size>

- AnyPortrait 에디터가 너무 작은 경우 렌더 텍스쳐와 관련된 에러가 발생하는 문제가 수정됨
- 화면 캡쳐시 배경 색상이 반투명한 경우, RGB 채널의 값이 Alpha 값에 영향을 받는 문제가 수정됨
- 애니메이션의 타임라인 등을 삭제한 후 실행 취소시, 키프레임의 데이터가 초기화되고 복원 불가 상태가 되는 문제가 수정됨
- 애니메이션의 타임라인 등을 삭제한 후 실행 취소시, 기즈모가 동작하지 않는 문제가 수정됨
- 메시 편집 화면에서 버텍스를 추가한 후 실행 취소 시, 기존의 버텍스들을 연결하는 선들이 모두 사라지는 문제가 수정됨
- Bake나 새로운 캐릭터를 생성한 후 정상적으로 실행 취소가 되지 않는 문제가 수정됨
- 유니티 2022 또는 이전 버전에서 작업 공간 좌측 상단에 이상한 이미지가 출력되는 문제가 수정됨
- 유니티 6에서 URP로 실행시, 커맨드 버퍼와 관련된 에러 로그가 발생하는 문제가 수정됨
- 유니티 6에서 타임라인 추가하기, 모디파이어 추가하기 등과 같은 일부 리스트 UI가 어색하게 출력되는 문제가 수정됨
- 유니티 2023 또는 이후 버전에서 메시의 버텍스를 복사하여 붙여넣는 UI가 다소 작게 출력되는 문제가 수정됨
- "Color Only (Controller)" 모디파이어를 편집할 때, 에디터 설정에 따라서 새로운 키(Key)를 추가할 때 객체가 보여져야하는 상태에서도 초기 Alpha가 0이 되어버리는 문제가 수정됨
- 리깅 편집 화면에서 브러시 아이콘이 화면 확대/축소에 따라 같이 확대/축소되는 문제가 수정됨
- Rigging, Physics 모디파이어에 등록된 메시를 삭제한 후 바로 에디터를 재시작하면, 에러로 인하여 모디파이어 편집이 불가한 문제가 수정됨
- 클리핑 마스크 메시가 숨겨졌다가 보여지는 프레임에서 클리핑 메시가 렌더링되지 않는 문제가 수정됨 (v1.6.1)
- 메카님으로 재생되는 두 캐릭터의 동기화가 해제될 때 에러가 발생되는 문제가 수정됨 (v1.6.1)

<size=16>Fichier de mise à jour AnyPortrait v1.6.0 / v1.6.1</size>
(30 avril 2025 / 6 août 2025)

<size=13>Améliorations</size>

- <color=blue>Masques</color>
    La possibilité de créer et d'envoyer une texture de rendu faisant office de masque a été grandement améliorée.
    Contrairement aux masques d'écrêtage, les masques peuvent être créés et envoyés quel que soit l'ordre de rendu des maillages.
    Plusieurs maillages peuvent créer un seul masque.
    Des propriétés personnalisées peuvent être transmises aux masques.
    La possibilité de combiner plusieurs masques est ajoutée.
    Au lieu d'un masque alpha, une texture de masque générée avec un shader standard peut être transmise avec la valeur Alpha pour implémenter un effet « See-Through ».
    L'option « Masque uniquement » a été ajoutée pour définir un maillage qui ne s'affiche pas réellement, mais sert uniquement de fournisseur de masque.
    Une option permettant de dimensionner les textures de rendu des masques en fonction de la taille de l'écran a été ajoutée.
    Des préréglages de matériaux « v16 » améliorés ont été ajoutés pour prendre en charge la fonctionnalité de masque, et les anciens préréglages et packages de matériaux sont classés comme « Legacy ».

- <color=blue>Ancrage de l'éditeur</color>
    L'éditeur AnyPortrait peut être exécuté ancré dans l'interface de l'éditeur Unity.
    Un problème a été corrigé : l'éditeur se fermait lorsqu'il était « maximisé » alors qu'il était ancré.
    Un problème survenant lors du passage à une autre scène alors que l'éditeur était ancré a été corrigé.

- <color=blue>Scripts liés à l'animation</color>
    Pour vérifier la durée de l'animation, les propriétés « TimeLength » et « Duration » ont été ajoutées à apAnimPlayData, et les fonctions « GetAnimationTimeLength » et « GetAnimationDuration » ont été ajoutées à apPortrait.
    Pour vérifier si l'animation est en boucle, la propriété « IsLoop » a été ajoutée à apAnimPlayData, et la fonction « IsAnimationLoop » a été ajoutée à apPortrait.
    L'événement « OnAnimationEnded » a été ajouté à apPortrait pour détecter la fin ou la dernière image de l'animation en cours de lecture.
    Les fonctions « PauseAt » et « ChangeFrame » permettant de modifier l'image d'une animation ont été ajoutées. (v1.6.1)

- <color=blue>Validation des options de cuisson</color>
    La validation automatique des options clés de cuisson a été ajoutée.
    Elles doivent être définies en fonction de l'environnement du projet, telles que « Pipeline de rendu », « Espace colorimétrique » et « Nombre de caméras ».
    Cette fonctionnalité est ajoutée à la boîte de dialogue Cuisson et certaines options sont déplacées vers l'onglet Paramètres.

- Amélioration : les « Propriétés réservées » utilisées dans AnyPortrait dans la « Bibliothèque de matériaux » sont automatiquement déterminées en fonction de l'élément de shader défini.
- Fonction « Déplacer symétriquement » dans l'écran d'édition du maillage.
- Une fonction a été ajoutée pour déplacer l'axe vers le pivot lors de l'utilisation de l'outil Miroir dans l'écran d'édition du maillage.
- Un fichier de définition d'assemblage (asmdef) a été ajouté afin que les scripts AnyPortrait soient compilés séparément.
- Les liens des pages Web ont été modifiés en raison du renouvellement du site Web (v1.6.1).



<size=13>Problème résolu</size>

- Un problème a été résolu où une erreur liée à la texture de rendu se produisait lorsque l'éditeur AnyPortrait était trop petit.
- Un problème a été résolu où la valeur du canal RVB était affectée par la valeur Alpha lorsque la couleur d'arrière-plan était semi-transparente lors de la capture d'écran.
- Un problème a été résolu où les données des images clés étaient initialisées et irrécupérables lors de l'annulation après la suppression de la chronologie d'une animation, etc.
- Un problème a été résolu où le gadget ne fonctionnait pas lors de l'annulation après la suppression de la chronologie d'une animation, etc.
- Un problème a été résolu où toutes les lignes reliant les sommets existants disparaissaient lors de l'annulation après l'ajout de sommets dans l'écran d'édition du maillage.
- Un problème a été résolu où l'annulation après la création d'un nouveau personnage ou d'une ébauche ne s'effectuait pas correctement. - Correction d'un problème où une image étrange s'affichait en haut à gauche de l'espace de travail dans Unity 2022 ou versions antérieures.
- Un problème a été résolu où un journal d'erreurs lié au tampon de commandes survenait lors de l'exécution avec URP dans Unity 6.
- Un problème a été résolu où certaines interfaces utilisateur de liste, telles que Ajouter une chronologie et Ajouter un modificateur, s'affichaient de manière anormale dans Unity 6.
- Un problème a été résolu où l'interface utilisateur pour copier-coller les sommets d'un maillage s'affichait de manière quelque peu réduite dans Unity 2023 ou versions ultérieures.
- Un problème a été résolu où l'alpha initial était de 0 lors de l'ajout d'une nouvelle clé, selon les paramètres de l'éditeur lors de la modification du modificateur « Couleur uniquement (Contrôleur) ».
- Un problème a été résolu où l'icône de pinceau dans l'écran de modification du rigging s'agrandissait ou se réduisait en fonction du zoom de l'écran.
- Un problème a été résolu où l'éditeur ne pouvait pas modifier les modificateurs en raison d'une erreur lors de la suppression d'un maillage enregistré dans un modificateur de rigging ou de physique, puis de son redémarrage immédiat.
- Un problème a été résolu où le rendu des maillages découpés dans les images où le masque de découpage était masqué puis affiché. (v1.6.1)
- Un problème a été résolu où une erreur lors de la synchronisation de deux personnages incarnant Mecanim. (v1.6.1)

<size=16>AnyPortrait-Aktualisierungsprotokoll v1.6.0 / v1.6.1</size>
(30. April 2025 / 6. August 2025)

<size=13>Verbesserungen</size>

- <color=blue>Masken</color>
    Die Möglichkeit, eine Rendertextur zu erstellen und zu senden, die als Maske oder Ähnliches fungiert, wurde erheblich verbessert.
    Im Gegensatz zu Clipping-Masken können Masken unabhängig von der Renderreihenfolge der Meshes erstellt und gesendet werden.
    Mehrere Meshes können zusammen eine Maske bilden.
    Benutzerdefinierte Eigenschaften können mit Masken übergeben werden.
    Die Möglichkeit, mehrere Masken zu kombinieren, wurde hinzugefügt.
    Anstelle einer Alpha-Maske kann eine mit einem regulären Shader generierte Maskentextur mit dem Alpha-Wert übergeben werden, um einen Durchsicht-Effekt zu erzielen.
    Die Option „Nur als Maske“ wurde hinzugefügt, um ein Mesh festzulegen, das nicht tatsächlich rendert, sondern nur als Maskenprovider dient.
    Eine Option zur Größenanpassung von Rendertexturen für Masken basierend auf der Bildschirmgröße wurde hinzugefügt.
    Verbesserte Materialvorgaben der Version 16 wurden hinzugefügt, um die Maskenfunktionalität zu unterstützen. Alte Materialvorgaben und -pakete wurden als „Legacy“ klassifiziert.

- <color=blue>Editor-Andocken</color>
    Der AnyPortrait-Editor kann im Unity-Editor-Layout angedockt ausgeführt werden.
    Ein Problem wurde behoben, bei dem der Editor im angedockten Zustand bei Maximierung beendet wurde.
    Ein Problem wurde behoben, das beim Wechsel zu einer anderen Szene im angedockten Zustand auftrat.

- <color=blue>Animationsbezogene Skripte</color>
    Um die Länge der Animation zu überprüfen, wurden die Eigenschaften „TimeLength“ und „Duration“ zu apAnimPlayData und die Funktionen „GetAnimationTimeLength“ und „GetAnimationDuration“ zu apPortrait hinzugefügt.
    Um zu überprüfen, ob die Animation in einer Schleife abgespielt wird, wurde die Eigenschaft „IsLoop“ zu apAnimPlayData und die Funktion „IsAnimationLoop“ zu apPortrait hinzugefügt.
    Das Ereignis „OnAnimationEnded“ wurde zu apPortrait hinzugefügt, um zu erkennen, wann die abgespielte Animation beendet ist oder das letzte Bild erreicht hat.
    Die Funktionen „PauseAt“ und „ChangeFrame“ zum Ändern des Frames einer Animation wurden hinzugefügt. (v1.6.1)

- <color=blue>Validierung von Bake-Optionen</color>
    Die automatische Validierung wichtiger Bake-Optionen, die an die Projektumgebung angepasst werden müssen, wie z. B. „Render-Pipeline“, „Farbraum“ und „Anzahl der Kameras“, wurde hinzugefügt.
    Diese Funktion wurde dem Bake-Dialog hinzugefügt, und einige Optionen wurden in den Reiter „Einstellungen“ verschoben.

- Die in AnyPortrait in der Materialbibliothek verwendeten „Reservierten Eigenschaften“ werden nun automatisch anhand des eingestellten Shader-Assets ermittelt.
- Funktion „Symmetrisch verschieben“ im Mesh-Bearbeitungsbildschirm.
- Eine Funktion zum Verschieben der Achse zum Drehpunkt wurde hinzugefügt, wenn das Spiegelwerkzeug im Mesh-Bearbeitungsbildschirm verwendet wird.
- Eine Assembly-Definitionsdatei (asmdef) wurde hinzugefügt, sodass AnyPortrait-Skripte separat kompiliert werden können.
- Webseiten-Links wurden aufgrund der Website-Erneuerung geändert. (v1.6.1)



<size=13>Problem behoben</size>

- Ein Problem wurde behoben, bei dem ein Fehler im Zusammenhang mit der Rendertextur auftrat, wenn der AnyPortrait-Editor zu klein war.
- Ein Problem wurde behoben, bei dem der Wert des RGB-Kanals durch den Alpha-Wert beeinflusst wurde, wenn die Hintergrundfarbe während der Bildschirmaufnahme halbtransparent war.
- Ein Problem wurde behoben, bei dem die Daten von Keyframes initialisiert und nicht wiederherstellbar waren, wenn nach dem Löschen der Zeitleiste einer Animation usw. eine Rückgängigmachung vorgenommen wurde.
- Ein Problem wurde behoben, bei dem das Gizmo beim Rückgängigmachen nach dem Löschen der Zeitleiste einer Animation usw. nicht funktionierte.
- Ein Problem wurde behoben, bei dem alle Linien, die vorhandene Scheitelpunkte verbinden, beim Rückgängigmachen nach dem Hinzufügen von Scheitelpunkten im Mesh-Bearbeitungsbildschirm verschwanden.
- Ein Problem wurde behoben, bei dem das Rückgängigmachen nach dem Erstellen eines neuen Charakters oder nach dem Backen nicht korrekt ausgeführt wurde.

<size=16>Dziennik aktualizacji AnyPortret v1.6.0 / v1.6.1</size>
(30 kwietnia 2025 / 6 sierpnia 2025 r.)

<size=13>Ulepszenia</size>

- <color=blue>Maski</color>
    Możliwość tworzenia i wysyłania tekstury renderowania, która działa jak maska ​​i podobne, została znacznie ulepszona.
    W przeciwieństwie do masek przycinających, maski można tworzyć i wysyłać niezależnie od kolejności renderowania siatek.
    Wiele siatek może tworzyć jedną maskę razem.
    Właściwości niestandardowe można przekazywać z maskami.
    Dodano możliwość łączenia wielu masek.
    Zamiast maski alfa, tekstura maski wygenerowana za pomocą zwykłego shadera może być przekazana z wartością Alfa, aby zaimplementować efekt „Przezroczystości”.
    Dodano opcję „Tylko jako maska”, aby ustawić siatkę, która faktycznie nie jest renderowana, ale służy jedynie jako dostawca maski.
    Dodano opcję zmiany rozmiaru tekstur renderowania dla masek na podstawie rozmiaru ekranu.
    Dodano ulepszone ustawienia wstępne materiału „v16” w celu obsługi funkcjonalności maski, a stare ustawienia wstępne materiału i pakiety są klasyfikowane jako „Starsze”.

- <color=blue>Dokowanie edytora</color>
    Edytor AnyPortrait można uruchomić zadokowany w układzie edytora Unity.
    Naprawiono problem, w którym edytor kończył działanie po „Zmaksymalizowaniu” w stanie zadokowanym.
    Naprawiono problem, który występował podczas przełączania się na inną scenę, gdy edytor był zadokowany.

- <color=blue>Skrypty związane z animacją</color>
    Aby sprawdzić długość animacji, właściwości „TimeLength” i „Duration” są dodawane do apAnimPlayData, a funkcje „GetAnimationTimeLength” i „GetAnimationDuration” są dodawane do apPortrait.
    Aby sprawdzić, czy animacja jest zapętlona, ​​właściwość „IsLoop” jest dodawana do apAnimPlayData, a funkcja „IsAnimationLoop” jest dodawana do apPortrait.
    Zdarzenie „OnAnimationEnded” jest dodawane do apPortrait w celu wykrycia, kiedy odtwarzana animacja się zakończyła lub osiągnęła ostatnią klatkę.
    Dodano funkcje „PauseAt” i „ChangeFrame” umożliwiające zmianę klatki animacji. (v1.6.1)

- <color=blue>Walidacja opcji wypieku</color>
    Dodano automatyczną walidację kluczowych opcji wypieku, które muszą być ustawione tak, aby pasowały do ​​środowiska projektu, takich jak „Render Pipeline”, „Color Space” i „Number of Cameras”.
    Ta funkcja została dodana do okna dialogowego wypieku, a niektóre opcje zostały przeniesione na kartę Ustawienia.

- Ulepszono to, że „Zarezerwowane właściwości” używane wewnątrz AnyPortrait w „Material Library” są automatycznie określane na podstawie ustawionego zasobu shadera.
- Funkcja „Move Symmetrically” na ekranie edycji siatki.
- Dodano funkcję przesuwania osi do punktu obrotu podczas korzystania z narzędzia Mirror na ekranie edycji siatki.
- Dodano plik definicji zespołu (asmdef), aby skrypty AnyPortrait były kompilowane osobno.
- Linki do stron internetowych zostały zmodyfikowane ze względu na odnowę witryny (v1.6.1).
